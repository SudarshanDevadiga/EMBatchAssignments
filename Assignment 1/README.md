# Flutter & Dart Assignment 🚀

A collection of Dart programs created as part of my Flutter/Dart learning assignments.
This repository focuses on understanding **Dart fundamentals, Object-Oriented Programming (OOP), collections, and libraries**.

## 📚 Topics Covered

The repository contains **10 tasks** covering important Dart concepts:

| Task | Topic        | File                     |
| ---- | ------------ | ------------------------ |
| 1    | Classes      | `task1_class.dart`       |
| 2    | Constructors | `task2_constructor.dart` |
| 3    | Methods      | `task3_methods.dart`     |
| 4    | Inheritance  | `task4_inheritance.dart` |
| 5    | Mixins       | `task5_mixin.dart`       |
| 6    | Interfaces   | `task6_interface.dart`   |
| 7    | Lists        | `task7_list.dart`        |

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/SudarshanDevadiga/-Flutter_Assignment.git
```

### 2. Navigate to the project

```bash
cd -Flutter_Assignment
```

### 3. Run the main file

```bash
dart run main.dart
```

You can also run individual tasks:

```bash
dart run task1_class.dart
```

Replace the filename with any task you want to execute.
